tbaMUD Web Portal

This GitHub Pages site is the web portal for the tbaMUD server. The MUD itself runs as a separate TCP service.

Server configuration

Host: localhost

Port: 4000

Protocol: Telnet / TCP

Use a Telnet/MUD client to connect to the host above on port 4000.

Important

GitHub Pages can serve this portal, but it cannot run the C-based tbaMUD server or make a raw TCP connection from browser JavaScript. Deploy the tbaMUD server separately and expose TCP port 4000.
